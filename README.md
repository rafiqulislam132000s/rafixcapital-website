# RafiX Capital Website
Black-and-gold static site for Cloudflare Pages.
- `index.html`: homepage
- `css/style.css`: shared design
- `js/common.js`: navigation/footer year
- `js/videos-data.js`: 450 slots; edit title, description, thumbnail and videoUrl
- `js/videos.js`: video card renderer
- `js/articles-data.js`: edit article title, summary and body
- `js/articles.js`: article listing renderer
- `video-page-1.html` through `video-page-15.html`: 15 pages, 30 slots each
- `article-page-1.html` through `article-page-7.html`: article listing pages
- `article-1.html` through `article-7.html`: individual articles
Leave videoUrl blank for empty slots. Keep folder structure and keep index.html at repository root.
